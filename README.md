# FPGA Labs

An index of Verilog coursework covering combinational logic, sequential logic and VGA display systems. FPGA 与数字逻辑实验总目录。

The original repository names are listed below so earlier coursework references remain easy to follow.

| Original repository | Organized repository | Focus |
| --- | --- | --- |
| `FPGA1` | [Lab 1 — Combinational Logic](https://github.com/chengmiao2005/FPGA-Lab1-Combinational-Logic) | One-bit full adder and comparator |
| `FPGA2` | [Lab 2 — Decoders and Latches](https://github.com/chengmiao2005/FPGA-Lab2-Decoders-and-Latches) | Six decoder coding styles and latch inference |
| `FPGA2-1` | [Lab 2.1 — Counter](https://github.com/chengmiao2005/FPGA-Lab2-Counter) | Clocked counting and LED toggle |
| `FPGA2-2` | [Lab 2.2 — Running Light](https://github.com/chengmiao2005/FPGA-Lab2-Running-Light) | Four-LED one-hot rotation |
| `FPGA3` | [Lab 3 — VGA Timing](https://github.com/chengmiao2005/FPGA-Lab3-VGA-Timing) | Raster timing and pixel/text rendering |
| `FPGA4` | [Lab 4 — VGA State Machine](https://github.com/chengmiao2005/FPGA-Lab4-VGA-State-Machine) | Color-bar, MUST and END display states |

## Related projects

- [Verilog Full Adder](https://github.com/chengmiao2005/Verilog-Full-Adder): standalone one-bit adder exercise.
- [FPGA Breakout Game](https://github.com/chengmiao2005/FPGA-Breakout-Game): the maintained game project, with source and documentation.

## Using the labs

Open an individual repository for its source layout, dependencies, simulation commands and validation record. The existing records distinguish static compilation from behavioral simulation and board validation. Archived integration files and incomplete examples are identified in the individual READMEs.

This index contains links and documentation. Source code remains in the individual repositories.
